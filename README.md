# F1 — Las Vegas Grand Prix 🏎️🌃

브라우저에서 돌아가는 F1 야간 레이스 게임. Three.js + 바닐라 JS, 빌드 도구 없음.

라스베가스 스트립 서킷(17코너, ~6.5 km)에서 7대의 AI와 풀 레이스를 펼칩니다.

## 실행

```bash
npm run dev        # http://localhost:3000
```

또는 아무 정적 서버로 루트를 서빙하면 됩니다 (`python3 -m http.server` 등).
Three.js가 로컬 번들이라 오프라인에서도 동작합니다.

## 조작

| 키 | 동작 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 브레이크 |
| A·D / ←·→ | 조향 |
| E | DRS 토글 (존 안에서만) |
| C | 카메라 (체이스 / 콕핏 / 노즈 / 드론) |
| R | 트랙 복귀 |
| 1 / 2 / 3 | 타이어 교체 (그리드에서만) |
| M | 음소거 |
| ESC | 일시정지 |

게임패드 지원: 왼쪽 스틱 조향, 트리거 가속/브레이크, A 버튼 DRS.

## 게임 시스템

- **차량 물리** — 벡터 동역학: 마찰 서클, 슬립각 드리프트, 다운포스, 브레이크 락업,
  휠스핀, 슬립스트림, 타이어 마모·온도 (소프트/미디엄/하드)
- **AI 레이스** — 곡률 기반 자동 레이싱 라인 + 속도 프로파일, 추월·방어, 스타트 반응속도
- **레이스 컨트롤** — F1 스타트 라이트(랜덤 홀드), 점프 스타트 페널티, 섹터 타임,
  라이브 델타, 패스티스트 랩, 순위 타워, 최종 결과 화면
- **라스베가스** — 애니메이션 Sphere, 벨라지오 분수, 하이 롤러 관람차, 네온 사인,
  서치라이트, 스키드 마크·타이어 스모크·스파크
- **사운드** — WebAudio 신디사이저 (엔진, 기어 시프트, 스키드, 바람) — 에셋 파일 없음

## 테스트

```bash
npm install   # three (테스트용 CJS 빌드)
npm test      # 헤드리스 시뮬레이션: AI가 실제 물리로 서킷을 3랩 주행
```
